## 🚀 快速开始

### 1. 安装依赖

```bash
cd ysy/outdoor-hiking-frontend
npm install
```

### 2. 配置环境变量

创建 `.env.development` 文件：

```env
VITE_API_BASE_URL=http://localhost:8080/api
VITE_AMAP_KEY=你的高德地图Key
```

### 3. 启动开发服务器

```bash
npm run dev
```

访问：`http://localhost:3000`

## 🗺️ 高德地图集成示例

### 1. 加载地图

```typescript
import AMapLoader from '@amap/amap-jsapi-loader'

useEffect(() => {
  AMapLoader.load({
    key: import.meta.env.VITE_AMAP_KEY,
    version: '2.0',
    plugins: ['AMap.Geolocation', 'AMap.Marker'],
  }).then((AMap) => {
    // 创建地图实例
    const map = new AMap.Map('map-container', {
      zoom: 15,
      center: [116.397428, 39.90923],
    })
  })
}, [])
```

### 2. 获取当前位置

```typescript
const geolocation = new AMap.Geolocation({
  enableHighAccuracy: true,
  timeout: 10000,
})

geolocation.getCurrentPosition((status, result) => {
  if (status === 'complete') {
    console.log('经度:', result.position.lng)
    console.log('纬度:', result.position.lat)
  }
})
```

## 🔐 JWT 认证流程

1. **登录** → 获取 token
2. **存储** → localStorage + Zustand
3. **请求** → Axios 拦截器自动添加 `Authorization: Bearer {token}`
4. **过期** → 401 响应 → 清除 token → 跳转登录
