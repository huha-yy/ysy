# 🚀 前端项目启动指南

## ⚠️ 当前报错原因

TypeScript 提示找不到模块（红色下划线），是因为 **还没有安装依赖包**。

这是正常现象，执行下面的步骤即可解决。

## ✅ 快速启动（3步）

### 1️⃣ 进入前端目录

```bash
cd ysy/outdoor-hiking-frontend
```

### 2️⃣ 安装依赖

```bash
npm install
```

> ⏱️ 预计需要 2-5 分钟（取决于网络速度）

### 3️⃣ 启动开发服务器

```bash
npm run dev
```

访问：http://localhost:3000

---

## 🔧 如果遇到问题

### 问题 1: npm 安装慢

**解决方案：** 使用淘宝镜像

```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### 问题 2: Node.js 版本过低

**要求：** Node.js >= 16

**检查版本：**
```bash
node -v
```

如果版本低于 16，请升级 Node.js。

### 问题 3: 端口 3000 被占用

**解决方案：** 修改 `vite.config.ts` 中的端口号

```typescript
server: {
  port: 3001, // 改成其他端口
}
```
